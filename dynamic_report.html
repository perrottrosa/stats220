Analysis of lecture attendance, engagement and duration

This report analyses lecture engagement based on lecture duration and attendance type.

variables:

  • lecture attendance type: how the lecture was attended e.g. online(recording) or in-person attendance.

  • lecture engagement: how engaging the lecture was, using an engagement score from 1(not engaging) to 5(very engaging).

  • lecture duration: how long the lecture was (measured in hours)

This report aims to:

  • analyse how engagement levels differed across attendance types e.g. does engagement vary depending on whether the lecture was attended in-person or online?

  • analyse distribution of attendance modes

  • analyses distribution of lecture duration (hours)

This section is a summary of the minimum, maximum and mean duration of lectures. This section analyses how engagement differs across attendance modes, which provides a mean engagement level for each mode of attendance.
